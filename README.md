# 🎓 Student Manager – Laravel Project

A simple Student Management System built using **Laravel** with authentication and role-based access.

## 🚀 Features
- User Authentication (Login / Register)
- Role-based access (Admin / User)
- Student CRUD (Create, Read, Update, Delete)
- Admin can Edit & Delete students
- Users have View-only access
- SQLite database
- Clean UI using Blade & Bootstrap

## 🛠 Tech Stack
- Laravel 12
- PHP 8+
- SQLite
- Blade Templates
- Bootstrap
- Git & GitHub
